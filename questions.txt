Practical 10: Payment System

Problem Statement:
Create a payment system using polymorphism.

Create:

Payment
 ├── CreditCard
 ├── UPI
 └── PayPal

Each class should implement:

make_payment(amount)

Sample Output:

Payment of ₹5000 made using Credit Card.
Payment of ₹2500 made using UPI.
Payment of ₹3000 made using PayPal.
